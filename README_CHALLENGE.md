# Repo Pack – 72h Challenge Mode (Voice Intelligence App)

Dieses Repository ist auf **schnelle Abgabe + Review** optimiert.

Prinzipien:
- Run > Perfektion
- Demo > Overengineering
- Klarheit > Vollständigkeit

## Erwartung für Reviewer
- Projekt lässt sich starten
- Hotkey → sprechen → Ergebnis
- Output ist kopierbar + als Datei speicherbar
- README erklärt Entscheidungen kurz und sauber

## Produktscope (MVP)
- Desktop-App (Electron) + Next.js UI
- Voice-Pipeline: Aufnahme → Transkription (offline-first; API optional) → Enrichment (LLM)
- 3 Presets: Meeting Note / Dev Ticket / Executive Summary
- Output: Clipboard + Markdown + History (last 10)

## Nicht-Ziele (bewusst OUT)
- Keine Cloud-Sync / Accounts
- Offline-first (funktioniert ohne Internet)
- Kein Multi-User
