# Mini Review Summary — Voice Capture Overlay

## Entscheidung
Wir liefern ein **stilles Desktop-Overlay**, das Sprache als Input nutzt und **Text direkt im aktiven Fenster** ausgibt.

## Warum
- Fokus auf **Produktivität statt Performance**
- Klare Kontrolle beim Nutzer (Hotkey, kein Always-on)
- **Offline-first** ist ernst gemeint, kein Marketing-Label
- Minimaler Scope → hohe Lieferwahrscheinlichkeit in 72h

## Kern-Flow
Hotkey → `Listening` → Sprechen → Ende erkannt → visuelles Processing → Overlay dimmt → **Text erscheint im aktiven Fenster**

## Bewusste Abgrenzungen
- Kein Text-to-Speech
- Keine Avatare / Persona / KI-Show
- Kein Cloud-Zwang
- Keine UI-Überladung

## Output
- Text-only
- Direkt dort, wo der Nutzer arbeitet
- Presets nur **opt-in**, Standard ist roher Text

## Trade-offs
- Weniger Features, dafür **klare Haltung**
- Kein „Wow“-Effekt, sondern **Alltagstauglichkeit**
- Audio nur als Input → geringeres Risiko, höhere Stabilität

## Ergebnis
Ein **werkzeughaftes, ruhiges Produkt**, das Denken unterstützt, statt Aufmerksamkeit zu binden.

Status: **Konzept final, Scope eingefroren, umsetzungsbereit**
